## Change Routing Notes

- Shared behavior belongs in app-services, ipc-api, adapter-ipc-grpc, daemon state, or a core crate before it is duplicated in CLI or tray.
- Runtime task, queue, and backpressure changes should start from this map and [network-v1.md](network-v1.md).
- Product-facing tray changes should still validate daemon/API behavior separately when state or workflow semantics change.
- Release and installer changes should update release evidence docs in the same PR when the evidence contract changes.
